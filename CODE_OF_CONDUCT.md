# Code of Conduct / Código de conducta

## Our pledge / Nuestro compromiso

We want this educational space to be welcoming to everyone, regardless of experience or background. / Queremos que este espacio educativo sea acogedor para todas las personas, sin importar su experiencia u origen.

## Expected / Esperado

- Be respectful and constructive. / Respeta a las personas y aporta comentarios constructivos.
- Help beginners with patience. / Ayuda a principiantes con paciencia.
- Respect privacy and consent. / Respeta la privacidad y el consentimiento.

## Not tolerated / No tolerado

Harassment, threats, hate speech, unwanted personal information, impersonation, or spam. / Acoso, amenazas, mensajes de odio, datos personales ajenos publicados sin permiso, suplantación o spam.

## Enforcement / Aplicación

The maintainer may edit or close discussions, reject PRs, or restrict participation to protect the community. / El mantenedor puede moderar conversaciones, rechazar PRs o restringir la participación para proteger a la comunidad.

Report problems privately using the maintainer's GitHub profile contact options rather than publishing sensitive details in an issue. / Reporta problemas de forma privada mediante los canales de contacto del perfil del mantenedor en GitHub; no publiques información sensible en un issue.
