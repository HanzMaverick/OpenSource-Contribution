## 🇺🇸 English

### What is this project?

Your safe first step into open source. Create a short Markdown introduction, open a Pull Request (PR), receive feedback, and learn how project collaboration works. **No programming experience required.**

### Your first PR in 5 steps

1. **Fork** this repository using the **Fork** button at the top right.
2. In your fork, open the `contributors/` folder and select **Add file → Create new file**.
3. Name your file `your-github-username.md` (lowercase), and copy the template from [`contributors/example.md`](contributors/example.md). Personalize every field.
4. Select **Commit changes**, then **Contribute → Open pull request** to send your changes to this repository's `main` branch.
5. Wait for the automated check, review feedback, and merge by a maintainer.

> **Important:** For your first contribution, change **only one new file** inside `contributors/`. Do not edit someone else's file. The automatic validator will check your format.

**More guidance:** [English step-by-step guide](docs/GUIDE_EN.md) · [Full contributing rules](CONTRIBUTING.md)

### What will you learn?

`Fork` → `Create a Markdown file` → `Commit` → `Pull Request` → `Review` → `Merge`

### Recognition

Merged contributions become part of the repository's history, and your introduction remains visible in [`contributors/`](contributors/). GitHub profile contribution graphs and badges follow GitHub's own eligibility rules; they are **not guaranteed** by this repository.

## 🇬🇹 Español

### ¿Qué es este proyecto?

Tu primer paso seguro hacia el open source. Crea una presentación corta en Markdown, abre una Pull Request (PR), recibe comentarios y aprende cómo colaboran los proyectos. **No necesitas saber programar.**

### Tu primera PR en 5 pasos

1. Haz un **Fork** de este repositorio con el botón de la esquina superior derecha.
2. En tu fork, abre `contributors/` y selecciona **Add file → Create new file**.
3. Ponle a tu archivo `tu-usuario-de-github.md` (en minúsculas), copia la plantilla de [`contributors/example.md`](contributors/example.md) y personalízala.
4. Presiona **Commit changes** y después **Contribute → Open pull request** para enviar tus cambios a la rama `main` de este repositorio.
5. Espera la validación automática, la revisión y la aprobación de un mantenedor.

> **Importante:** En tu primera contribución modifica **únicamente un archivo nuevo** en `contributors/`. No modifiques el archivo de otra persona. El validador comprobará el formato.

**Más detalles:** [Guía paso a paso en español](docs/GUIDE_ES.md) · [Reglas de contribución](CONTRIBUTING.md)

### ¿Qué aprenderás?

`Fork` → `Crear archivo Markdown` → `Commit` → `Pull Request` → `Revisión` → `Merge`

### Reconocimiento

Las contribuciones aceptadas pasan a formar parte del historial del repositorio y tu presentación queda visible en [`contributors/`](contributors/). Las contribuciones y los logros del perfil de GitHub están sujetos a los requisitos de GitHub: **no se garantizan** por participar aquí.
