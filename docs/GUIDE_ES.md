# 🇬🇹 Tu primera Pull Request — guía paso a paso

¡No necesitas instalar ningún programa! Puedes completar el ejercicio desde el navegador.

## 1. Haz un Fork

Entra al [repositorio original](https://github.com/HanzMaverick/OpenSource-Contribution), inicia sesión y presiona **Fork → Create fork**.

## 2. Crea tu archivo

En **tu fork**, entra a `contributors/`, presiona **Add file → Create new file** y escribe el nombre `tu-usuario.md` (exactamente el usuario de GitHub en minúsculas).

Copia la estructura de [`contributors/example.md`](../contributors/example.md) y cambia el nombre, el enlace de GitHub y la descripción. No edites `example.md`.

## 3. Guarda el cambio (commit)

Presiona **Commit changes**, escribe un mensaje como `docs: add tu-usuario contributor profile` y confirma. Puedes crear una rama nueva (recomendado) desde el editor.

## 4. Abre la Pull Request

En tu fork selecciona **Contribute → Open pull request**. Confirma que la base sea `HanzMaverick/OpenSource-Contribution`, rama `main`, y el origen sea tu fork. Describe lo que aprendiste.

## 5. Espera revisión

La acción automática revisará tu archivo. Si falla, abre el resultado en **Checks**, corrige el archivo en la misma rama y el chequeo volverá a ejecutarse. Si pasa, un mantenedor todavía deberá revisar y hacer merge.

## Conceptos clave

- **Fork:** copia del repositorio en tu cuenta.
- **Branch:** línea separada de cambios.
- **Commit:** registro de un cambio.
- **Pull Request:** propuesta para incorporar cambios al repositorio original.
- **Merge:** incorporación de los cambios aprobados.

> Un PR aceptado forma parte del historial del proyecto; GitHub decide qué actividad muestra como contribución en el perfil. No hay badges garantizados.
