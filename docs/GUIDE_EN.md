# 🇺🇸 Your first Pull Request — step by step

No software installation needed! You can finish this exercise directly in your browser.

## 1. Fork

Visit the [original repository](https://github.com/HanzMaverick/OpenSource-Contribution), sign in, and select **Fork → Create fork**.

## 2. Create your file

In **your fork**, open `contributors/`, select **Add file → Create new file**, and name it `your-username.md` (your exact GitHub username, lowercase).

Use the structure from [`contributors/example.md`](../contributors/example.md) and replace the sample name, GitHub URL, and bio. Do not edit `example.md`.

## 3. Commit

Select **Commit changes** and use a message such as `docs: add your-username contributor profile`. Creating a new branch in the editor is recommended.

## 4. Open a Pull Request

In your fork, select **Contribute → Open pull request**. Ensure the base repository is `HanzMaverick/OpenSource-Contribution`, branch `main`, and the head is your fork. Describe what you learned.

## 5. Review

The automated check will inspect your file. If it fails, click **Checks**, fix your file on the same branch, and the check will run again. Passing does not mean automatic approval; a maintainer still reviews and merges it.

## Key terms

- **Fork:** your own copy of a repository.
- **Branch:** a separate line of changes.
- **Commit:** a recorded change.
- **Pull Request:** a request to integrate your changes into the original project.
- **Merge:** accepting approved changes into a branch.

> A merged PR becomes part of project history, but GitHub decides what activity appears in profile contribution graphs; no achievements are guaranteed.
